# sinema — сайт кинотеатра

Учебный проект на C# / ASP.NET Core MVC, .NET 10. При первом запуске создаются демо-афиша и расписание на 30 дней. Данные приложения хранятся в SQLite-файле `App_Data/cinema.db`. При первом запуске существующие данные из `App_Data/cinema.json` импортируются в SQLite автоматически. JSON-файл оставлен как резервная копия.

## Запуск

1. Установите .NET 10 SDK.
2. Откройте `CinemaSite.csproj` в Visual Studio или откройте терминал в папке проекта.
3. Выполните `dotnet run` и откройте адрес, который выведет приложение.

## Демо-доступы

- Администратор: `admin@cinema.local` / `Admin123!`
- Менеджер: `manager@cinema.local` / `Manager123!`

Перед развёртыванием смените эти демонстрационные пароли. Пользователи могут зарегистрировать свои учётные записи через сайт.

## Что реализовано

- Главная страница со слайдером, динамической афишей, расписанием на месяц, FAQ и контактами.
- Отдельные страницы кинотеатра, залов, услуг, бронирования, отзывов, контактов, кабинета и команды.
- Регистрация, вход, пароль хранится в виде PBKDF2-хеша; доступ ограничен ролями.
- Бронирование мест с проверкой занятости, сохранением заказа и историей в личном кабинете.
- Профиль пользователя, смена пароля, отмена ожидающей брони.
- Админ-панель: редактирование афиши и расписания, управление пользователями и ролями, бронированиями, контактами и FAQ; модерация отзывов.
- Формы отзывов и обратной связи сохраняют данные для обработки.
- Адаптивная вёрстка для телефона и компьютера.

## Ограничения демо-версии

Онлайн-оплата картой не подключена по вашему выбору; менеджер вручную обновляет статус заказа. Контактные данные оставлены текущими. JSON-хранилище подходит для демонстрации на одном экземпляре; для реального развёртывания нужна СУБД, резервные копии и настройка секретов. Изображения хранятся локально в `wwwroot/images`, поэтому сайт не зависит от внешних фотохостингов.
